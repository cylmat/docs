# Instructions

Write a comment above every function describing its purpose and parameters.

## The comment should be in the following format:

/**
  Function Name: FUNCTION_NAME
  Purpose: Describe the purpose of the function here.
  Parameters:
  - param1: Description of the first parameter.
  - param2: Description of the second parameter.
  - ...
*/

## Explanation

This is done to improve readability across the project.
